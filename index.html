How it works

  1. Claim an Agent ID in the Binance app (Wallet > Agent ID). One per user, non-transferable.
  2. Connect your wallet here. The page reads your Agent ID directly from the Agent ID contract on BNB Chain.
  3. Press “Check in now” and confirm in your wallet. The contract records your streak and points on-chain.
  4. Come back every day. Miss a day and your streak restarts at 1.

AgentCheck holds no funds and collects no personal data. There is no server, no login, and no QR code sign-in. The contract has no payable functions and no withdrawal function. The only owner permission is pause/unpause for emergencies — see the README for the full disclosure.

AgentCheck — built for the Agent ID Hackathon. Not affiliated with Binance. Check-in costs only network gas; no returns or rewards are promised.
