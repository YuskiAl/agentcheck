How it works

Option 1 — Browser wallet

  1. Claim an Agent ID in the Binance app (Wallet > Agent ID). One per user, non-transferable.
  2. Connect your wallet here. The page reads your Agent ID directly from the Agent ID contract on BNB Chain.
  3. Press “Check in now” and confirm in your wallet. The contract records your streak and points on-chain.
  4. Come back every day. Miss a day and your streak restarts at 1.

Option 2 — Binance Agentic Wallet (via your AI agent)

  1. Claim an Agent ID and enable Developer Mode in the Binance App (Agentic Wallet > Settings).
  2. Copy the prompt in the agent guide below and paste it to your AI agent (Binance AI Pro, Claude, Codex, or any agent with the official Binance Skills).
  3. Your agent checks Developer Mode, checks whether you already checked in today, previews the check-in, and waits for your confirmation.
  4. Confirm in the Binance App. Your streak appears on the leaderboard here.

Check in with the AgentCheck Skill

A skill package for AI agents: install it once, and your agent knows how to check you in every day — Developer Mode check, today’s status, preview, your confirmation, then execute and verify. Same safety rules as the prompt below: preview first, nothing executes without your confirmation.

Check in with your AI agent (Binance Agentic Wallet)

Your Agent ID lives in your Agentic Wallet, inside the Binance App. The wallet only signs through your own AI agent — this site never asks you to scan a QR code or enter a pairing code, and it never asks for your seed phrase or private key.

Before you start

  1. Claim an Agent ID in the Binance App (Wallet > Agent ID banner).
  2. Enable Developer Mode in the Binance App: Agentic Wallet management page > Settings. It can only be switched on in the App, and it expires — re-enable it when it lapses. Your agent can check with baw wallet settings --json (look for devMode.enabled).
  3. Use an AI agent with the official Binance Skills installed — Binance AI Pro in the App, or Claude / Codex / any agent that ran npx skills add binance/binance-skills-hub/skills/binance-web3/binance-agentic-wallet.

Copy this prompt to your agent

Check me in to AgentCheck (Agent ID daily check-in) on BNB Smart Chain.

1. First check: is Developer Mode enabled on my Agentic Wallet? Run `baw wallet settings --json` and read devMode.enabled and devMode.expiresAt. If it is disabled or expired, stop and tell me to enable it in the Binance App (Agentic Wallet -> Settings).
2. Check whether I already checked in today: call hasCheckedInToday(my Agentic Wallet address) on 0x69951ec1e92d9dC5C587cdD672006C04ef32e3D7 (BNB Smart Chain, chain 56). If I already checked in today, stop and tell me.
3. Preview the check-in: `baw contract-call preview --binanceChainId 56 --from <my Agentic Wallet address> --to 0x69951ec1e92d9dC5C587cdD672006C04ef32e3D7 --value 0 --inputData 0x183ff085 --json`. This calls checkIn() - one daily check-in, no tokens sent, only network gas. The contract is verified on BscScan.
4. Show me the preview and wait for my explicit confirmation. Do not execute before I confirm.
5. After I confirm, run `baw contract-call execute --requestId <requestId from the preview> --json` and show me the transaction hash.
6. Verify on-chain that my streak and points updated, and show me my new streak. You can check the leaderboard at https://agentcheck-hazel.vercel.app/

Your agent previews the transaction first, you confirm it in the Binance App, and only then it is sent. Nothing executes without your confirmation. Check-in costs only network gas.

Safety

AgentCheck holds no funds and collects no personal data. There is no server, no login, and no QR code sign-in. The contract has no payable functions and no withdrawal function. The only owner permission is pause/unpause for emergencies — see the README for the full disclosure.

Cost

Check-in costs only network gas. No returns or rewards are promised.
